<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:type" title="Typed vars, not raw objects">`tweenVars`, `scrollTriggerVars`, `draggableVars` and the rest are interfaces, so a misspelled property is a compile error instead of a silently ignored tween.</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="The whole free surface">Core engine, the `Animation`/`Tween`/`Timeline` hierarchy, `gsap.utils`, every easing and every plugin GSAP ships free since 3.13.</ktjs-feature>

<ktjs-feature icon="lucide:plug" title="Plugins that actually register">The plugin class objects are `val`s read through the module import, so importing them is what registers the plugin — the same side effect the npm package relies on.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">The module's tests create real tweens against real elements, and the demo has its own Playwright suite that also checks the language switch.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, with the same structure, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
