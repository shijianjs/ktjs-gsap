<ktjs-feature icon="lucide:type" title="带类型的 vars，而不是裸对象">`tweenVars`、`scrollTriggerVars`、`draggableVars` 等都是接口：属性拼错是编译错误，而不是补间被静默忽略。</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="覆盖全部免费部分">核心引擎、`Animation`/`Tween`/`Timeline` 层次、`gsap.utils`、全部缓动，以及 3.13 起随包免费的每个插件。</ktjs-feature>

<ktjs-feature icon="lucide:plug" title="真正会注册的插件">插件类对象是通过模块导入读到的 `val`，读到它就是注册插件 —— 与 npm 包依赖的同一个副作用。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">模块的测试对真实元素创建真实补间，演示页另有 Playwright 套件，连语言切换一起验证。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，结构一致，并各自跳转到演示页与 Dokka API 文档。</ktjs-feature>
